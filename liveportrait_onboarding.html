Project Snapshot What LivePortrait Delivers

LivePortrait animates a source portrait using the motion of a driving video, with controls for eye and lip retargeting, stitching, and privacy-preserving motion templates.

Key Features

  • Real-time portrait animation with human and animal modes.
  • Stitching and retargeting controls for precise eye and lip motion.
  • Supports still images, videos, and reusable motion templates.
  • Cross-platform: Linux, Windows, macOS (partial).

Novelty

  • Efficient motion template system for fast inference.
  • SPADE-based generator for high-quality frame synthesis.
  • Stitching network that preserves natural boundaries.
  • Fine-grained retargeting for lip-sync and gaze control.

Performance (RTX 4090)

  • Face detection: 15-20 ms.
  • Feature extraction: 8-12 ms.
  • Motion transfer: 20-30 ms.
  • Total pipeline: 68-97 ms (10-15 FPS).

Quick Start Environment & First Run

Environment Setup

  1. Clone the repo: git clone https://github.com/KwaiVGI/LivePortrait
  2. Create env: conda create -n LivePortrait python=3.10
  3. Install deps: pip install -r requirements.txt
  4. Download weights into pretrained_weights/.

Entry Points

  • app.py: Gradio UI (human).
  • app_animals.py: Gradio UI (animals).
  • inference.py: CLI batch processing.
  • speed.py: Performance benchmarking.

Architecture System Layers & Pipeline

The pipeline orchestrates motion transfer by coordinating UI entry points, preprocessing utilities, and neural modules.

User Interfaces (Gradio UI, CLI)
        │
Pipeline Layer (LivePortraitPipeline, AnimalPipeline, GradioPipeline)
        │
Core Components (LivePortraitWrapper, Cropper, Motion Templates)
        │
Neural Modules (F: Feature, M: Motion, W: Warping, G: SPADE, S&R: Stitching)
        │
Synthesized Frames -> Post-processing -> Outputs

Processing Phases

  1. Input Processing: validation, face detection, cropping.
  2. Feature Extraction: appearance and motion embeddings, keypoints, rotations.
  3. Motion Processing: template creation, retargeting ratios, motion smoothing.
  4. Animation Loop: transform keypoints, generate dense motion, synthesize frames, apply stitching.
  5. Post-processing: paste-back, temporal smoothing, audio muxing.

Core Components Where to Look First

Component Location Highlights
LivePortraitPipeline src/live_portrait_pipeline.py Primary orchestrator: executes pipeline, builds motion templates, prepares video assets.
LivePortraitWrapper src/live_portrait_wrapper.py Neural inference entry point: feature extraction, keypoint transformation, stitching hook.

GradioPipeline src/gradio_pipeline.py Wraps pipeline with UI-specific logic for previews, controls, and error handling.

Neural Modules Model Building Blocks

Module Summary

  • F - Appearance Feature Extractor: ResNet backbone, multi-scale, 3D features.
  • M - Motion Extractor: ConvNeXtV2 base, keypoint and expression outputs.
  • W - Warping Module: Dense motion field generation plus occlusion estimation.
  • G - SPADE Generator: Progressive upsampling and SPADE normalization.
  • S&R - Stitching & Retargeting: Networks for lip and eye control with boundary smoothing.

Helpful Specs

  • Input resolution: 256x256 (upsampled to 512 in generator).
  • Keypoints: 21 primary landmarks from Module M.
  • Half-precision inference controlled via InferenceConfig.flag_use_half_precision.
  • Retargeting networks expose stitching, lip, and eye heads for fine-tuning.

Project Structure Navigating the Repo

Top-Level Highlights

  • src/: core code (config, modules, utils, pipelines).
  • assets/: docs, examples, UI assets.
  • pretrained_weights/: model checkpoints (download separately).
  • animations/: default output directory.
  • Dockerfile, requirements*.txt, readme*.md: deployment and docs.

Inside src/

  • config/: configuration classes such as argument_config.py, crop_config.py, inference_config.py.
  • modules/: neural blocks (appearance_feature_extractor.py, motion_extractor.py, warping_network.py, spade_generator.py, stitching_retargeting_network.py).
  • utils/: preprocessing, I/O, retargeting utilities, InsightFace dependencies, XPose animal support, and enhancement models.
  • live_portrait_pipeline.py, live_portrait_pipeline_animal.py, live_portrait_wrapper.py, gradio_pipeline.py: core runtime.

Data Flow From Inputs to Animated Frames

  1. User Input: source portrait plus driving video or template.
  2. Preprocessing: InsightFace detects faces, extracts landmarks, crops and aligns frames.
  3. Feature Extraction: Module F encodes appearance; Module M derives keypoints, expressions, and rotation matrices.
  4. Animation Generation: Motion templates adjust trajectories, Module W builds dense motion, Module G synthesizes frames, S&R applies stitching and retargeting.
  5. Post-processing: Results are pasted back to the original frame, smoothed temporally, and combined with audio if provided.
  6. Outputs: final animation plus optional motion template for reuse.
